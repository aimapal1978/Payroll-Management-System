Payroll Management System for a Restaurant

This project is a web-based payroll management system designed for restaurant employees. It helps managers organize employees by department, including the Chefs, Kitchen Staff, Cashier, and Cleaning Staff sections.

The system allows the manager to add new employees, set their basic single-shift salary, record single-shift and full-time working days, and enter advances or deductions. It automatically calculates each employee’s total earnings and final net salary. Users can also view detailed salary information, clear salary data, or delete employees.

The application was developed using HTML, CSS, and JavaScript. Employee data is stored in the browser’s Local Storage, allowing the information to remain available after refreshing or reopening the page. The interface uses a responsive table layout and a salary details popup for easy management and review.
